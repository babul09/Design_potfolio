# AI × Design Engineering Portfolio

A responsive, static portfolio site designed to showcase projects at the intersection of AI, computational design, and workflow automation.

## Run locally

No build step or package installation is required.

1. Download and extract the project.
2. Open `index.html` in a browser, or serve the folder with a local static server.
3. Edit `site-config.js` with your name and links.
4. Update the About section in `index.html` with accurate education and skills.
5. Replace placeholder project status and links as work progresses.

For a local server, from this directory run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy

This is a static website. You can deploy the folder using GitHub Pages, Netlify, or Vercel.

### GitHub Pages

1. Create a public GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In repository Settings → Pages, choose deployment from the `main` branch and root folder.
4. Wait for the published URL, then test it on mobile and desktop.
